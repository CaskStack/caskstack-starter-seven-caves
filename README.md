# Seven Caves Distillery — CaskStack Starter Kit

> **Ludicrously Small Batch Craft Spirits • Grain-to-Glass & Cane-to-Glass**

A bespoke, standalone Statamic / Blade starter kit engineered specifically for craft distilleries, micro-distilleries, and artisanal spirit houses, based on the craft and coastal ethos of **Seven Caves Distillery** in San Diego, CA.

---

## 🌊 Design & Brand System

- **Typography**:
  - Headings: `EB Garamond` (Classic maritime & master distiller serif)
  - Body: `Karla` (Modern geometric sans)
  - Metrics / Tech Specs: `Space Grotesk` (Technical batch and proof ratings)
- **Palette**:
  - `seven-navy`: `#0C1821` (Deep Pacific Midnight)
  - `seven-teal`: `#1B4965` (La Jolla Sea Spray)
  - `seven-copper`: `#C27835` (Direct-Fired Copper Pot Still)
  - `seven-sand`: `#F7F4EE` (Sun-Bleached Sandstone)

---

## 🥃 Feature Highlights

1. **Distillery Hero & Manifesto**: Pot still visual showcase with live 120-bottle micro-batch statistics.
2. **Sea Caves Narrative**: 7-pillar heritage block inspired by the natural sea caves of La Jolla Cove.
3. **Interactive Spirit Matrix**: Real-time category filtering across Artisanal Rums, Botanical Gins, Single-Cask Whiskeys, and Exploratory releases.
4. **Exploratory Micro-Vault**: Limited-run allocated pantry items, barrel-aged maple syrups, and bespoke bitters.
5. **Tasting Room & Speakeasy Reservation Engine**: Miramar San Diego distillery tour and flight booking.

---

## 📦 Installation & Usage

Install via the Statamic CLI or CaskStack Theme Hub:

```bash
php please starter-kit:install CaskStack/caskstack-starter-seven-caves
```

Or clone directly:

```bash
git clone git@github.com:CaskStack/caskstack-starter-seven-caves.git
```
